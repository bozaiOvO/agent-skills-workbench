# 一手来源台账

这个文件用来回答一个问题：

**当前这版峰哥 skill 的核心结论，到底是不是从一手语料里提出来的？**

答案：是。

## 一手来源定义

在这个项目里，一手来源主要指：

- `orginal_text/*.txt`

这些文件直接对应直播/转写原文，保留了峰哥的口气、停顿、临场反应和错误前提处理方式。

## 二手或加工来源

辅助来源包括：

- `refine_data_process/10_feng_sft_train.json`
- `refine_data_process/01_punc_transcripts/*`

它们主要用于：

- 提炼更干净的问答骨架
- 交叉验证某类问题是否有稳定回答模板

## 当前结论

如果只看这版 skill 的核心推理依据：

- 主证据明显以 `original_text` 为主
- SFT 只是辅助压缩和验证

因此这版可以被视为：

- **一手来源主导**

而不是：

- “只指向目录、但没有真正用语料产出结论”
