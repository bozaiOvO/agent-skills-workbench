# QA Rubric

## Test 1 结构吻合度

检查：
- 是否完整贴合 `IP_Criteria` 的结构链

失败信号：
- 少阶段
- 跳结构

## Test 2 钩子有效性

检查：
- 前 3 句是否清晰匹配某个钩子公式

失败信号：
- 开头平
- 没冲突
- 没人群

## Test 3 IP 味儿浓度

检查：
- 是否保留竞品的判断节奏、句式密度、气味

失败信号：
- 只有几个口头禅
- 变成普通助手腔

## Test 4 权力姿态一致性

检查：
- 是否保留原 IP 的说话位置
- 是否保留“谁在判断谁”的关系

失败信号：
- 原来像裁判，结果写成客服
- 原来像直播间连麦，结果写成公众号说明文
- 原来是上对下判断，结果变成过度平衡的助手腔

## Test 5 世界观一致性

检查：
- 是否保留原 IP 默认的真实观、判断逻辑、信任来源

失败信号：
- 只学了口头禅，没学到底层判断
- 原 IP 靠一线经验，生成稿却像空理论
- 原 IP 靠市场判断，生成稿却变成抽象价值观

## Test 6 反 AI 味测试

检查：
- 是否太顺
- 是否太圆
- 是否太想一次讲完
- 是否太像“正确总结”

失败信号：
- 每句都太工整
- 太会归纳，缺少现场感
- 没有具体场景，只有道理
- 像材料整理，不像真人开口

## Test 7 去重测试

检查：
- 是否真正完成赛道迁移
- 是否没有照抄原案例

失败信号：
- 生硬替换词
- 保留原领域强痕迹

## Test 8 受众适配测试

检查：
- 目标用户是否听得懂
- 决策者是否买账

失败信号：
- 太专业
- 太虚
- 目标受众错位

## Test 9 业务安全测试

检查：
- 有无过度承诺
- 有无自伤
- 有无误导

失败信号：
- “一定高薪”
- “100%通过”
- 为了流量把自己行业讲死

## Test 10 转化承接测试

适用于课程 / 培训 / 咨询类业务。

检查：
- 结尾 CTA 是否自然
- 是否顺着内容本身收口

失败信号：
- 前面讲内容，后面突然硬卖
- 留资动作与正文脱节
