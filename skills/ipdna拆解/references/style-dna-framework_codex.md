# Style DNA Framework

适用于：

- 真人 IP
- 知识型 IP
- 教育 / 咨询 / 服务 / 课程类 IP
- 强判断、强观点、强直播间人格的内容业务

不适用于：

- 剧情号
- 搬运号
- 主要靠剪辑表演起效的账号

## 核心原则

不要把“大而全的文风理论”直接塞进生成环节。

正确做法是：

1. 用深分析看透这个 IP
2. 再压缩成能指导生成的 `voice DNA`
3. 再把关键字段结构化进 `IP_Criteria`

目标不是写论文，
而是回答：

- 这个人为什么像他自己
- 为什么观众会信
- 为什么 AI 容易写不像

---

## 从大框架压缩成 8 个实战字段

### 1. 一句话定义

写法：

- 这个 IP 是一个什么位置的人
- 用什么方式影响观众

例子：

- `一个站在市场一边、喜欢先下判断再给路径的人`

### 2. 真实观 / 世界观

不要写空词。

要写：

- 他把什么当作真实
- 他默认怎么理解问题
- 他最常打掉的幻觉是什么

### 3. 真理来源 / 信任来源

拆清：

- 靠结果
- 靠经历
- 靠身份
- 靠一线观察
- 靠案例密度
- 靠直播间压迫感

### 4. 权力姿态

必须回答：

- 他是平等聊天
- 过来人提醒
- 老师式教导
- 行业裁判
- 还是直播间里直接“压着你走”

### 5. 典型钩子和论证法

至少写清：

- 怎么开头
- 怎么转折
- 怎么举例
- 怎么收口

### 6. 句式和词汇

只保留真正影响味道的：

- 常见起手句
- 常见转折句
- 常见判断句
- 常见动作句

### 7. 风格雷达图

固定 6 维：

- `真实性`
- `权力`
- `情感`
- `逻辑`
- `具体`
- `行动`

每维 `1-10` 分。

### 8. 核心矛盾

最少找 2 条：

- 他哪里既强硬又接地气
- 哪里既像权威又像聊天
- 哪里既高密度判断又不至于像 PPT

矛盾点常常就是“像本人”的关键。

## 生成 `style_report_codex.md` 时建议结构

1. 一句话概括
2. 真实观 / 世界观
3. 真理来源 / 信任来源
4. 权力姿态
5. 典型开头
6. 典型论证方式
7. 句式 / 词汇 / 节奏
8. 六维雷达图
9. 核心矛盾
10. 可迁移 / 不可迁移

说明：

- 这是研究层
- 可以比 `voice_dna_codex.md` 稍微厚一点
- 但仍然要服务生成，不要写成纯论文

## 生成 `voice_dna_codex.md` 时建议结构

这是给人和 AI 都能快速看的压缩版。

建议格式：

```md
# Voice DNA

## 一句话
[一句话说明这个 IP 的核心气质]

## 说话位置
- [speaker_role]
- [authority_score]
- [relation_to_audience]

## 他靠什么让人信
- [trust_source 1]
- [trust_source 2]

## 典型起手
- [句式 1]
- [句式 2]
- [句式 3]

## 典型转折
- [句式 1]
- [句式 2]

## 典型收口
- [句式 1]
- [句式 2]

## 他最常打的痛点
- [pain 1]
- [pain 2]

## 不能只学什么
- [口头禅]

## 六维雷达
- 真实性：X/10
- 权力：X/10
- 情感：X/10
- 逻辑：X/10
- 具体：X/10
- 行动：X/10
```

## 从深分析映射到 `IP_Criteria` 的方法

### 哲学基础

压缩进：

- `style_dna.philosophy_profile`
- `worldview`

### 权力关系

压缩进：

- `style_dna.power_posture`
- `audience_model`

### 修辞 / 句法 / 词汇

压缩进：

- `hook_patterns`
- `structure`
- `lexicon`
- `prompt_pack`

### 情感 / 美学 / 节奏

压缩进：

- `style_dna.style_radar`
- `lexicon.sentence_rhythm`

### 矛盾点

压缩进：

- `style_dna.contradictions`
- `transfer_rules.must_rewrite`

## 反 AI 味提醒

如果生成稿开始出现下面这些症状，
说明 `voice DNA` 压缩失败了：

- 太顺
- 太圆
- 太会总结
- 太像一个懂逻辑的助手
- 太像“把正确的话说了一遍”
- 口头禅像了，但人没像

这时候要回头补 3 件事：

1. 权力姿态有没有写准
2. 信任来源有没有写准
3. 典型矛盾有没有写准
