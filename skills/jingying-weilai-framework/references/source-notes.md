# Source Notes

## 本 skill 的主要来源

### 一手/近一手书籍信息

- 《经营未来》公开书籍信息、目录与试读摘录
- 中文书籍平台对该书的章节标题、前言、部分章节内容和摘录

主要用于确认：

- 书名、作者、译者、出版社、出版时间
- 章节结构
- 贫穷、现代集团、海外工程、转入政界、首尔治理等主线
- “信任”“经营”“主人意识”“现在能做什么”等可迁移概念

### 二手人物资料

- 百科类和新闻类资料中对李明博早年经历、现代集团经历、首尔市长和韩国总统经历的基本说明

主要用于确认：

- 李明博从企业经营者到政治人物的基本轨迹
- “首尔 CEO”这类叙述的外部语境
- 本书不能覆盖后续全部历史评价这一边界

## 当前版本可信度策略

- 书籍结构：中高
- 核心经营模型：中高
- 章节细节完整性：中
- 对李明博完整政治人生的判断：低，必须另行查证

## 为什么这样处理

用户没有提供本地全文。

因此当前版本不是“逐页精读版”，而是“公开资料稳健蒸馏版”：

- 优先提取反复出现且可迁移的经营模型
- 不编造具体章节细节
- 对自传偏差和后续争议保留诚实边界

## 后续可升级方向

如果以后补充本地全文或扫描文本，可以升级三块：

1. 增加按章节的精读卡片
2. 增加原文摘录与译文术语表
3. 增加“已知案例测试”，用书中案例验证 skill 的回答风格和判断顺序
