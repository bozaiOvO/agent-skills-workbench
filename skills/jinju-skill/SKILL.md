# Jinju Skill

## Mission

Write lines that feel sharp, real, and memorable. Prefer conflict over comfort, clarity over prettiness, and spreadability over self-indulgence.

## Decide the Task Type

- Use `Batch Lines` when the user gives a topic, track, or mood and wants multiple lines.
- Use `Script Integration` when the user also asks for short-video or podcast structure, opening hooks, endings, visuals, or BGM.
- Use `Rewrite Upgrade` when the user provides existing copy and wants it sharpened.

## Infer the Track First

- Infer the main track before writing: `职场`, `人性`, `商业`, or `认知`.
- Default to the most spreadable track if the user is vague.
- Use these anchors:
  - `职场`: replaceability, hierarchy, performance, negotiation, value pricing
  - `人性`: vanity, fear, desire, projection, transactional behavior
  - `商业`: traffic, conversion, margin, leverage, market indifference
  - `认知`: self-deception, delayed cost, framing traps, structural blind spots

## Non-Negotiables

- Write in simplified Chinese.
- Keep each line short, usually 18 to 32 Chinese characters.
- Prefer one sentence; use two only when the contrast needs a turn.
- Make every line carry a stance, a trade-off, or a hidden cost.
- Make it readable as a card and speakable in one breath.
- Use at least one of these engines: contrast, reversal, dismantling, psychological strike.
- Keep the tone sober, sharp, and grounded in real incentives.

## Ban List

- Do not write empty inspiration or comforting clichés.
- Do not use phrases like:
  - `只要努力就会成功`
  - `做自己就好`
  - `熬过去就好了`
  - `你若盛开……`
- Do not pad with vague words like:
  - `成长`
  - `蜕变`
  - `热爱`
  - `坚持`
  - `相信`
  - `未来可期`
- Do not output multiple lines that only swap synonyms.
- Do not soften the truth before exposing the tension.

## Core Engines

### 1. Contrast Gap

Use when the point becomes stronger through opposition.

Pattern:
`怕X，所以失去Y；敢Z，才换来A`

### 2. Era Pressure

Use when the line needs a larger backdrop such as platform logic, organizational change, or market reality.

Pattern:
`时代/平台/组织 不会因为过去的努力而持续奖励你`

### 3. Brutal Truth to Rebuild

Use when the user needs both a punch and a way out.

Pattern:
`先拆幻想，再给更硬的重构方式`

### 4. Psychological Strike

Use when the hidden blocker is not skill on the surface, but identity, fear, ego, or habit underneath.

Pattern:
`真正限制你的，不是表层问题，而是更深的机制`

## Workflow

### Batch Lines

1. Identify the visible topic.
2. Name the hidden pain and the common illusion.
3. Generate 6 lines by default.
4. Use at least 3 different engines in the batch.
5. Limit each engine to at most 2 lines per batch.
6. Add one short usage note after each line.

### Script Integration

1. Decide whether the scene is short video or podcast.
2. Put the strongest conflict line in the first 3 seconds.
3. Put the most discussable line at the ending.
4. Output exactly these blocks:
   - `【视觉画面/BGM建议】`
   - `【配音文案】`
5. Keep the spoken copy rhythmic and easy to breathe.

### Rewrite Upgrade

1. Preserve the user's core point.
2. Remove softness, repetition, and abstract filler.
3. Strengthen conflict, specificity, and cadence.
4. Return 3 variants:
   - `更狠版`
   - `更稳版`
   - `更适合口播版`

## Output Rules

### Batch Lines Format

`1. 金句`

`使用场景：...`

### Script Format

`【视觉画面/BGM建议】`

`【配音文案】`

### Rewrite Format

`更狠版：...`

`更稳版：...`

`更适合口播版：...`

## Final Self-Check

Delete the weakest lines before sending. Keep only lines that pass all checks:

- Can it stand alone as an image card?
- Can it be spoken without stumbling?
- Does it contain real tension?
- Can any word be cut without losing force?
- Does it sound like a human with edge rather than a template machine?
