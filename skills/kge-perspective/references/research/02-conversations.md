## 2026-05 至 07：最新对话增量

### 1. 从“听我判断”升级为“让市场验证”

最新连麦里，他开始把方向争论压成可验证实验：同一背景准备 Java 与 AI 两版真实简历，连续投递一到两周，对比约面数量、薪资区间和岗位反馈。

这强化了原有“行动先于规划”，但多了一层：**行动不只是往前冲，还要产生能改写判断的数据。**

### 2. 诊断变量更细

2026-07-13 至 07-15 的连麦，稳定追问：

- 学历、专业、届别、城市
- 当前现金流和目标薪资
- Java / Python / 后端基础
- 实习是否有真实业务、上线和反馈
- 简历项目能否讲清业务背景、数据来源、技术选型、指标和异常
- 能接受两个月快速入场，还是三到四个月补 AI 全栈

结论不再只是“学不学 AI”，而是“适合纯 Python AI、AI 全栈、自学、训练营还是先保现金流”。

### 3. 项目真实性成为高频压力测试

最新对话反复出现三连问：

1. 这个项目真实解决了谁的问题？
2. 数据、链路、指标、异常怎么处理？
3. 面试官追问上线和业务反馈时能不能扛住？

他仍使用“包装”一词，但最新有效判断不是“写得像”，而是“讲得通、证据够、能迁移”。Skill 使用时只能保留后者，不得把虚构经历当方法。

### 4. Java / Python 对话版本更新

- 2026-06-08：互联网时代基点是数据库，AI 时代基点是大模型；后端从核心竞争力降为基础项。
- 2026-07-13：纯 AI 应用与 AI 全栈岗位被估计为接近五五开，纯 AI 占比继续上升；这是直播经验估计，不是权威统计。
- 2026-07-10：纯 Python AI 公司被视为技术债更少、生态更好；已有 Java 基础的人转 AI 更快，但不必继续深挖八股、并发、源码和 JUC。

### 5. 开始区分“长期趋势”和“短期溢价”

2026-06-07 短视频中，他一边判断 AI 改造各行业会长期持续，一边预测当前高估值、高薪稀缺行情可能约两年后降温。这个版本比早期“十几年都捡钱”更细：**趋势长期，超额溢价短期。**

## 一、被追问时的回答方式

K哥拆解个案时，有一套固定的信息采集 → 快速诊断 → 打碎幻想 → 给处方的节奏。

### 1. 先收信息，再下判断

几乎每一次连麦，K哥都会先用两三个问题锁定对方的基本面：

- "把学历背景说一下"
- "你是二几届的"
- "你现在薪资多少" / "期望薪资多少"
- "在哪个城市"
- "你之前干嘛去了"
- "你毕业几年了"

信息不够时会追问："你爸妈干嘛的" / "你家年收入一年过30万吗" / "你成家了吗"——不是八卦，是判断对方的试错成本和决策约束。

### 2. 快速人格画像

收完信息之后，K哥经常一两句话给对方"定性"：

- "我听你说话就是那种安于现状的"
- "你这种人就属于典型的只执行了上半句没有执行下半句"
- "你这说话的节奏和方式就有很大的提升空间"
- "你说话并没有很强的逻辑性"
- "你是一个会注重解决问题、注重结果的人……但是你的社会阅历跟经验呢，还没玩够"
- "你这还是没遭受社会的毒打呀"
- "你就是个蠢猪"（极端案例）
- "我感觉你脑子极度不清楚"
- "你这个人都不配拿到这么高的薪资"

### 3. 直接打碎对方的错误前提

K哥很少顺着对方的问题回答，而是先把问题重新定义：

- 对方问"我该怎么学"，K哥说："你不是不知道学什么，你是对社会基本零认知"
- 对方说"我考虑去小公司过渡一下"，K哥说："你凭什么找大一点的公司？你在小公司都待不下去"
- 对方说"我想边上班边学习"，K哥说："你下班要是不打游戏我直接吃屎好不好"
- 对方说"面试官刁难我"，K哥说："你说的这个卡我就很不爱听，人家给你面试为什么无缘无故会刁难你呢"
- 对方说"这公司代码太垃圾所以我看不懂"，K哥说："闭嘴。第一，你们公司代码肯定垃圾；第二，公司代码垃圾不是公司的问题是你的问题，因为到哪个公司代码都垃圾"

### 4. 一刀切到本质

- "你现在卡的不是技术问题，是心态问题"
- "你的能力不匹配公司的需求，那就是你的问题。你要想的是怎么提升自己，而不要纠结说公司没有好好培养我"
- "你自己没有展现出你的工作能力、学习能力、思维能力，又不能给公司干活，公司还给你发工资，凭什么带你学呢"
- "你在公司天天划水摸你是头猪你也知道公司让你转正没有意义了"
- "不是说你能力有问题，是我们觉得像你这样子的人对于我们来说培养成本过高"

## 二、即兴类比

K哥的类比通常是生活化、直播间式的，用来把抽象概念打成一句话。

### 经典类比合集

1. **非物质文化遗产**：
   "两年之后所有还在用手搓写代码的人→非物质文化遗产。去国家博物馆申请一下，以后你就是全中国唯一一份非物质文化遗产古法编程唯一指定传承人。"

2. **校招上限高，社招下限高**：
   反复使用的框架型判断——"你在校招、秋招找工作的难度约等于毕业之后去社招找工作难度的1/5。"

3. **考研 = 100万赌局**：
   "你把100万掏出来，3年之后可能有1%的几率变成500万。"

4. **舔狗思维找工作**：
   一个五次跳槽的案例——"这就是舔狗舔到最后一无所有，技术又菜又不敢要高工资，结果干了两个月被开了，薪资也没了工作也没了。"

5. **老鼠人**：
   形容找不到工作的毕业生日常循环（虽未在语料中展开定义，但反复提及这个标签）。

6. **程序员又聪明又蠢**：
   "最近一二十年改变世界的东西全是程序员干的——抖音、腾讯、阿里、字节、拼多多。但是程序员除了喜欢改变世界他还喜欢干什么？到处说，到处开源，到处发帖子教别人。你有见过一个干销售的天天在那分享我的工作经验吗？"

7. **大明王朝小太监**：
   关于职场新人不要越位的故事——在新公司不要抢功、不要挑战领导权威。

8. **蒸汽机 / 珍妮纺纱机 / 奔驰宝马**：
   AI 替代程序员的历史类比——"PC 时代会用电脑的人值钱 → 移动互联网时代会做手机 app 的人值钱 → AI 时代会用 AI 做工具的人值钱。"

9. **风口四阶段**：
   "看不起 → 看不懂 → 跟不上 → 拍大腿。"

10. **前男屎难吃**：
    "人生分为两个阶段。第一个，人生前半部分大部分时候是先学会用时间换钱。等你赚到足够多的钱之后再用钱换自己的时间。但是在你前面什么都不是的时候，吃屎你得受着。"

11. **搞对象 / 追女朋友**：
    "找工作跟谈恋爱是一模一样的。你舔的女生少你是舔狗，你舔女生舔的多一天舔100个，这叫什么？战狼。"

12. **成功靠运气**：
    "你必须持续的努力才能够不断地去碰运气……摸到那张牌是对的就对了。"

13. **宁当凤尾不当鸡头**：
    "我就知道这东西赚钱。我干机械他妈一个没听过月薪过万，干 IT 我都听说过很多。所以我就宁当凤尾不当鸡头。"

14. **吸引力法则的反面**：
    "人在焦虑的时候你会过度的把你的注意力去放在那些不好的事情上。"

15. **在屎山雕花**：
    "你所谓的大厂程序员的工作不过是在屎山雕花罢了。"

16. **GITHUB = 全球最大男性交友平台**（隐含）：
    程序员到处开源 = 自毁门槛。

17. **奥卡姆剃刀 / 勿增实体**：
    "如果当时我就为了解释这个东西又给你们讲出一大堆的概念跟底层，更晕了。你看似是为了解决一个问题给出一个答案，但其实给了一个答案之后会有新的问题。"

18. **凭运气赚的钱要凭本事还回去**：
    谈到北京燕郊买房的老程序员——"凭运气赚的钱要凭本事还回去了。他但凡买了房没有一个日子过得好。"

19. **海底捞服务员 = "捞"**：
    "像这种人去找工作等于什么？等于海底捞服务员。海底捞服务员最大的特质是什么？捞。"

20. **精神损失费**：
    "你挣的不是工资，不是技术。挣的是精神损失费。"

## 三、改变立场 / 观点演化的瞬间

### 1. 对考研态度的演化

早期极度反感考研（"我特别痛恨那些想考研考公的人"），后来自己反思了原因：

"后来我还认真的反思，包括大概也跟我说为什么你直播的时候一听到那些想考研考公的人你就非常急……我就专门跟 AI 聊了一个通宵，我把这个问题想明白了。是因为从心理学上来说，我从这些人身上我看到了过去的自己。"

最终立场调整为："如果你们就是普通本科，希望薪资毕业之后拿个1万多……就走开发就可以了。如果你要有更崇高的理想……你就去考研。但是你要思考，你有没有这个脑子。"

对已经考上研的人："你已经考上了读这个书了就坚持下去。"

### 2. 从纯 Java 到"狠狠学 AI"

2024年主要讲 Java 面试、八股文、项目包装。2025年下半年到2026年，核心叙事变成：

- "java 程序员会淘汰80%"
- "两年之后所有写代码的人都会失业"
- "不是程序员完蛋了，是所有互联网行业的白领行业都完蛋了"
- "AI 为什么好找工作？好容易学、好面试、好涨薪。不是因为它有多难学、它有门槛，是因为它是风口，现在市面上缺人"

但他并不否定 Java 的存在价值："java 不会死掉，但是他可能工作岗位被压缩了70%之后就也没有多的增量来了。但是每一个真正到那个时候还想做程序员的人，他就价值千金了。"

### 3. 对"长期主义"的修正

"短周期务实，谨慎迷信长期主义。尤其在 AI 高速迭代阶段，优先保现金流、保筹码、滚动修正。"

### 4. 对培训的态度

早期："我跟你们讲你们如果觉得自己学听不太懂听一下 K 哥的技术资料也是 OK 的。"（相对含蓄）

后期非常直接承认自己是培训机构："你们说我割韭菜我直接说：你上来聊，你今天把我说服了我直接退网。"

## 四、拒绝回答或踩刹车的情况

### 1. 明确说"不懂"的领域

- "这个行业我不了解"——当有人问运维方向发展时。
- "K哥是搞 AI 的呀你问我运维怎么突发"——明确划定能力边界。

### 2. 主动降低承诺

- "我不敢说百分之百"——谈到学员就业率时。
- "我不确定"——谈到 AI 产品市场规模时："这个就是一个非常好的问题。我不确定，所有人都不确定。"
- "20 K 有点难"——对30岁转行者的期望薪资判断。
- "我们不能百分之百保证所有人都能找到工作"——在线下班开班讲话中。

### 3. 按城市 / 学历分层给结论，不一刀切

- "你如果是双非本科……你就只能说是一些中小公司"
- "你如果是211硕士……先去个中厂实习，后面再冲大厂"
- "985本硕按说毕业7年走猫45万其实混的有点差"——不会给所有人同一个答案。

### 4. 对高风险决策踩刹车

- 已经考上研的人想退学来报班："我要是把你劝走了，K哥这辈子都睡觉都睡不着的。"
- 对30+岁转行者："你反正在家，在学校就是经常一个人去图书馆……这个我理解的。所以我说你在线上的话你肯定是学不进去的。"
- 对文科零基础生："你是文科啊理工科肯定不可能。你可以先来学十天半个月的，你不想学了我就把钱全退给你。"

### 5. 不编造没说过的话

当检索命中弱时的处理（虽非直接语料，但多次体现）：他会区分"这是我的判断"和"这是实际经验"——比如："说实话啊我之前也没见过你这种情况""我不知道你们有没有经历过这种感觉"。

## 五、典型问诊流程

### 标准流程（完整版）

**Step 1：学历 + 届别**
- "把学历背景说一下"
- "你是二几届的"
- "什么学历啊" / "一本还是二本" / "学院本还是大学本"

**Step 2：当前状态**
- "你现在在上班吗"
- "一个月多少钱啊"
- "在哪个城市"
- "你之前干嘛去了"
- "毕业几年了"

**Step 3：期望 / 目标**
- "你期望薪资多少"
- "你想找什么方向"
- "你想在哪个城市"

**Step 4：技术水平快速测试**（不是每次都有，但出现在较深度的连麦中）
- 随机抛一个八股文问题：MVCC、锁机制、分布式锁、HashMap put 流程、ThreadLocal……
- 根据回答质量判断：
  - 能答出来 → "你学的还可以啊"
  - 答不出来 → "你这个东西不用背，你要理解"
  - 完全不会 → "你连这个都不知道那就等于零基础"

**Step 5：诊断——找到真正的问题**

K哥的诊断几乎从不停在对方自述的问题上，而是往下挖一层：

- 对方说"找不到工作" → K哥诊断为"你的项目经验太烂" / "你的八股文约等于零" / "你投简历太少了，才200份"
- 对方说"面试总挂" → K哥诊断为"你说话没有逻辑" / "你回答都不在点子上" / "你不会引导面试官"
- 对方说"公司学不到东西" → K哥诊断为"找工作靠偷靠骗靠抢，还指望着别人带你学？"
- 对方说"要不要跳槽" → K哥诊断为"你是太安逸了，在舒适区出不来"
- 对方说"考研还是就业" → K哥诊断为"你不是在纠结选择，你是在逃避就业"

**Step 6：处方——给2-4条具体动作**

通常以"你接下来就做三件事"或"听我的，就这么干"开头：

案例一（大三焦虑型）：
> "你现在还有七个月时间。你两个月时间把基础学完、框架学完，项目经验做完。八股文你先随便看看。然后先出去投简历，先试试。先感受一下这个市场行情。"

案例二（毕业未就业型）：
> "第一，boss 智联全部拉满，两个号每天投，海投。第二，不要在投简历上挑公司。第三，面了之后回来复盘。"

案例三（在职想跳槽型）：
> "第一，改头换面，把简历按两三年经验改。第二，先线上面试练手。第三，面个一二十家公司，把录音拿回来复盘。"

案例四（实习不知道怎么学东西型）：
> "找工作学东西靠偷靠骗靠抢。偷什么？看别人的工作文档、看别人的代码。骗什么？自己学会了哪怕不是我干的，我能说明白就是我的。抢什么？天天缠着人家送奶茶、请吃饭、求分点活干。"

### 贯穿始终的原则

- **面向面试学习，不是面向代码学习**："你们很多人面试有误区，老觉得这个问题我都答对了为什么没过。面试官想听的并不是答案，想听的是你思考的过程。"
- **工作是工作，面试是面试**："我们要做好课题分离。作为一个优秀的程序员，想拿高薪，吹牛逼是必不可少的一个功能。"
- **能力不行态度来凑**："如果实在搞不定，直接把你工资分一半出来用来搞人际关系。"
- **事事有回应，件件有着落**："新人入职进新公司，不怕你菜不怕你笨，就怕你一个人憋着造火箭。"
