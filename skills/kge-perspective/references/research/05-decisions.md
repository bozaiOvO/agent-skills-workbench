# K哥重大决策记录、个人经历与行动模式

## 2026-05 至 07：最新决策增量

### 决策8：从 Java+AI 进一步转向 Python-first

- **背景**：2026-03/04 的课程与内容仍大量使用“Java+AI”“AI 全栈”。
- **新判断**：到 2026-07，他明确把纯 Python AI 应用公司视为更理想的增量市场；Java+AI 更多对应存量团队、历史系统和混合用工。
- **保留项**：已有 Java 的工程能力不会白学，后端 CRUD 和基础编程思维仍有用。
- **放弃项**：Java 八股、高并发、源码、JUC 和中间件深挖不再是普通 AI 求职者的首要投资。

### 决策9：把“学技术”改成“做业务闭环”

- 2026-05-21 把高薪来源解释为业务价值，而不是技术难度；传统企业用 AI 降本提效，可能比技术最难的开发工具更愿意付钱。
- 2026-05-28 明确认为用 Cursor/AI 完成真实需求也是成长；价值在解决问题，不在手写多少代码。
- 2026-06/07 的直播进一步要求项目能讲清业务、数据、指标、异常和复盘，并能从一个项目抽象出可迁移能力。

### 决策10：用市场实验替代口头争论

面对“继续 Java 还是转 AI”，最新方法是：准备两版真实简历，投递一到两周，比较面试数量、薪资和岗位反馈，再决定主路线。这是“行动先于规划”的可测量版本。

### 决策11：将 AI 学习周期按路线拆分

- 纯 Python + AI 应用：直播口径约两个月可开始求职。
- AI 全栈：通常三到四个月或更久，需要补基础后端/前端与工程能力。
- 已有 Java / 后端基础：转 Python 和 AI 的边际成本更低。

这些是培训与连麦场景中的经验估计，不是普遍成功率，也不能转写成就业保证。

### 决策12：承认高溢价窗口会降温

2026-06-07 首次明确预测：AI 作为长期产业趋势不会停，但当前高估值、高薪稀缺行情可能约两年后冷却甚至出现“寒冬”。行动策略因此变成：**先入场兑现，再持续更新技能，不把一次课程当终身饭票。**

### 业务变化与证据边界

- 2026-07-08 已出现“AI 线下 17 班”内容，说明培训业务继续扩张并完成 AI 化。
- 2026-06-23 公开提出“就业率 100%、平均薪资 15K”作为班级目标。只能记录为目标，不能当作已验证结果。
- 最新直播更强调筛选：没学习状态、现金流不稳、方向认知不足的人，不一定适合马上报班。

## 三、K哥的决策框架（给别人建议时的逻辑）

- 自律性差的人（十个人里八个自律性不好）

### 什么情况建议自学
- 自律性好的人："完全没有必要报班"
- 有编程基础、能自己看文档学习的人
- 时间充裕、不急于就业的人

### 什么情况建议考研
- K哥整体对考研持负面态度
- 唯一正面情况：学历确实太差（专科），且有明确目标院校，且个人意志坚定
- 但他仍然更推荐先就业再考虑

### 什么情况建议转AI
- 几乎所有人。这是他2025-2026年的核心观点
- 在职Java程序员：在职学习，花几个月时间转
- 应届生：直接学AI应用开发
- 已有开发经验的人：学大模型开发，薪资更高

### K哥决策框架的底层逻辑
1. **供需关系决定价值**：不是技术难不难，而是市场需不需要你
2. **风口大于个人努力**："时代的进程远远大于个人努力"
3. **先赚钱再说**："所有不以涨薪为目的的学习都是耍流氓"
4. **不要追求完美再行动**："你永远也不可能把所有东西全部都准备好"
5. **用结果验证方向**：先投简历面试，通过市场反馈调整，而非闭门造车

## 四、言行一致性分析

### 一致的地方

1. **"靠自己"的信念贯穿始终**
   - 他自己经历：三次把希望寄托在别人身上（叔叔公司、CTO带他、跟公司上市），三次吃亏

2. **"先行动再优化"**
   - 他自己：第一次面试坐反地铁、5分钟被刷，但立刻调整继续面
   - 他给别人的建议："千万不要说准备好了再去投简历，直接投"
   - 高度一致

3. **"面试比工作重要"**
   - 他自己：所有业余时间花在学习面试上，在公司省出时间看八股文
   - 他给别人的建议："赚钱才是目的""在公司学业务学实践，下班学理论学面试学吹牛"
   - 高度一致

4. **承认运气的作用**
   - 他说："所有人赚钱都是靠运气""我也赚钱靠运气"
   - 他也说："成功的人不愿意承认自己赚钱靠运气"

5. **做培训但不包就业**
   - 他明确说"不包就业""甚至不能保证你能学完课"
   - 他对其他培训班的批评也是"包就业是骗人的"
   - 一致

### 值得注意的张力（不完全矛盾，但有张力）

1. **"培训班教的不好"vs"来K哥这报班"**
   - 他反复批评培训班：教学快、内容浅、拔苗助长、就业率低、包就业是骗局
   - 但他自己做的就是培训班
   - 他的自洽逻辑：他的培训班和传统培训班不一样——筛选生源、敢劝退、老师都有大厂经验、一个月发四五十万工资
   - 评估：这不是矛盾，而是"我看到行业的问题，所以我做一个更好的"。但他的收入确实依赖于不断招生

2. **"技术不是最重要的"vs 靠教技术赚钱**
   - 他反复强调：找工作最重要的是心态、包装、面试技巧，技术只是基础
   - 但他的培训班核心还是教技术+面试
   - 自洽逻辑：他教的不只是技术，而是"面向面试的学习方法"+"包装能力"+"心态建设"

3. **"包装简历"的道德灰区**
   - 他明确教学员包装（Boxing）：编项目经验、虚报工作年限、把培训经历包装成工作经历
   - 他说"你但凡面试时候说你是自学的直接没人要""你只能说自己上过班"
   - 他也说"真真假假，虚虚实实结合才是正儿八经靠谱的逻辑"
   - 这和他"做人要真实"的其他表述有张力，但他的自洽逻辑是：市场规则如此，适者生存

4. **"赚钱靠风口"vs"要持续学习"**
   - 一方面说赚钱靠运气、靠风口
   - 另一方面又说要不断学习、不断卷
   - 自洽逻辑：努力是让你有"摸到好牌"的资格，但摸到什么牌是运气

## 五、对培训行业的态度

### 他对传统培训班的批评（具体且尖锐）

1. **教学质量差**
   - "MYSQL就讲三天""LINUX加起来就两天"
   - "讲的内容不会有网上视频全面"
   - "拔苗助长""完全没有网上视频那种讲的完整"
   - 培训班的学员出来"MYSQL有几个隔离级别""HashMap底层数据结构"这些基本问题都答不上来

2. **就业承诺是骗局**
   - "包就业可能就是给你内推销售或数据标注这种外包岗位"
   - "培训班说年前找不到工作还可以回来继续学习"——他直斥这是"培训班的说法，好像真心为你好"
   - "你在那学了六个月都没找到工作你还要再去学六个月吗？"

3. **老师脱离实战**
   - "很多培训班的老师都是脱离真正职场、脱离真正面试的，纯教科书式的教学"
   - "你让一个从来没找过工作的人教你找工作，你觉得这是现实吗？"

4. **行业口碑烂**
   - "传统线下培训班基本上口碑已经烂掉了""能叫得出名字的培训班都在大连上倒闭"
   - "就业率不到20%"

### 他自己做培训的逻辑

1. **差异化定位**："我是靠帮培训班擦屁股起家的"——先做面试辅导，帮培训班出来的差生找工作，然后做自己的培训
2. **老师标准严格**：自己以外"基本都是百万年薪起步，要么自己出过畅销书籍"
3. **敢淘汰学生**：阶段考核不通过就退学、留级或劝退
4. **不招不合适的人**：不招大一大二的（不急）、不招应届大专（"智商低、学习习惯差、没挨过社会毒打，三样占一样"）、不招天天打游戏的
5. **筛选生源**："来的人有1/3送过外卖进过厂，有一半考过研考过公，毫无例外都失败了"

### 他的核心态度总结

K哥对培训行业的态度可以概括为：**行业是烂的，但需求是真实的。** 他承认大部分人自律性差、自学学不进去，培训作为一种教育形式有存在价值。他的策略是做"不一样的培训"——严进严出、实战导向、面向就业。

他没有回避自己做培训赚钱这件事，甚至公开说"一个月发工资四五十万"。但他的自我叙事是：我自己是培训班出来的，我知道培训班的问题在哪，所以我做得比别人好。
