# Frameworks

## 1. 选题树四层法

### 第 1 层：总命题
你真正想说的判断。

例：
- 不是所有坚持都值得鼓励
- 普通家庭最怕的不是孩子不努力，而是努力方向错了
- 家长最容易被“体面专业”骗掉时间窗口

### 第 2 层：冲突点
让人纠结、误判、争论、付代价的地方。

常见冲突：
- 要不要继续读
- 要不要换赛道
- 要不要死磕一个低回报目标
- 要不要为了体面放弃结果
- 要不要相信学校 / 专业 / 证书天然有用

### 第 3 层：具体场景
必须出现人和节点。

场景模板：
- 孩子已经 ___，但家庭正在 ___
- 家长以为 ___，结果真正卡住的是 ___
- 学生看起来很努力，实际上一直在 ___
- 毕业 ___ 年后，才发现 ___

### 第 4 层：传播切口
优先从这 6 类切：

1. 具体动作：考研、考公、转专业、学 Java、投简历、实习、培训
2. 明确代价：三战、花钱、耗时间、错窗口、压家庭、低薪熬年限
3. 结果落差：以为稳定，结果难就业；以为体面，结果没出路
4. 家长痛点：钱、时间、孩子情绪、路径判断
5. 反常识判断：不是越努力越有用
6. 节点触发：大三、毕业、秋招、 gap、二战、三战

## 2. 标题自检五问

出完标题后，逐条问：

1. 我写清楚是谁了吗？
2. 我写清楚他在干什么了吗？
3. 我写清楚这件事为什么痛了吗？
4. 我写清楚我反对/提醒/主张什么了吗？
5. 去掉情绪词后，这个标题还剩信息吗？

如果第 2 和第 3 条答不上来，通常就是“假具体”。

## 3. 开头公式

### 公式 A：对象 + 具体动作 + 判断
- 很多家长看到孩子还在三战考研，第一反应不是心疼，是不敢劝。

### 公式 B：对象 + 代价 + 反常识
- 普通家庭最怕的，从来不是孩子不努力，而是他在一条高成本低回报的路上越走越远。

### 公式 C：场景 + 误判 + 提醒
- 孩子每天都在图书馆，不代表这条路就值得继续走。

### 公式 D：节点 + 决策 + 后果
- 大三下学期还在纠结要不要继续考研的家庭，最怕再拖半年才看懂现实。

## 4. 从一句模糊话拆出 10 个题

原句：很多家长看到孩子现在还在咬牙坚持，心里会觉得……

先补全“坚持什么”：
- 坚持考研
- 坚持考公
- 坚持学一个并不适合的专业
- 坚持找对口但几乎没岗位的工作
- 坚持死磕低回报赛道

再换冲突：
- 心疼，但不敢劝
- 努力很多，但方向错了
- 已经投入太多，舍不得止损
- 父母不懂行业，不知道该不该拦
- 孩子把坚持当信仰，家长把沉没成本当希望

再换切口，就能扩成一串题：
- 很多家长不敢劝孩子放弃三战考研，不是心软，是怕自己背锅
- 孩子还在咬牙坚持考公，家长最怕的不是失败，是又耗一年
- 普通家庭最怕孩子太懂事：明明扛不住了，还在硬撑
- 最难劝的，从来不是不努力的孩子，而是方向错了还特别能熬的孩子
- 家长最容易误判的一种努力，就是看起来很拼，结果离现实越来越远

## 5. 讲师批改标准

### 60 分
- 有对象
- 有主题
- 但模糊词太多
- 传播抓手弱

### 75 分
- 对象和动作清楚
- 有一点冲突
- 但代价和态度还不够尖锐

### 85 分
- 对象、动作、代价、判断齐全
- 能打动特定人群
- 有传播性

### 95 分
- 不只是清楚，还带节点、情绪和风险
- 能让目标受众立刻代入
- 能自然导向后续内容或转化
