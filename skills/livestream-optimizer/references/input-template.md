# Input Template

Use this when you want a consistent intake format for livestream reviews.

```text
请用 $livestream-optimizer 帮我复盘这场直播。

背景
- 行业:
- 产品/服务:
- 客单价:
- 目标人群:
- 平台:

本场直播目标
- 主要转化动作:
- 次要目标:

材料
- 直播逐字稿:
- 关键数据:
- 我自己觉得最卡的地方:

输出要求
- 先判断真正的问题是不是话术问题
- 给我最该改的 3 个点
- 重写开场、一个中段过渡、结尾 CTA
- 给下一场直播的执行清单
```

## Minimal Version

If the user is in a hurry, this is enough:

```text
请用 $livestream-optimizer 复盘这段直播逐字稿。重点看开场、人设、结构、成交动作，告诉我最该改的 3 个地方，并直接重写。
```
