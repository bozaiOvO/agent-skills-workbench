# Reading Guide

## 这份 skill 怎么陪读

### 陪读模式的目标

不是替用户读完，而是帮用户建立三样东西：

1. 命题树的骨架感
2. 每段到底在解决什么问题
3. 哪些地方是文本本身，哪些地方是解释学延伸

## 默认陪读流程

### 场景 A：用户没读过，想入门

默认路径：

1. 前言
2. 1
3. 2.01 到 2.063
4. 2.1 到 2.225
5. 3 到 4.0641
6. 4.111 到 4.1212
7. 5.6 到 5.641
8. 6.4 到 7

每轮输出格式：

- 这段在做什么
- 只抓一个主问题
- 只记两个关键词
- 一处误读提醒
- 下一步读到哪里停

### 场景 B：用户卡在某个编号

先做四件事：

1. 说明这条编号挂在哪条主命题下面
2. 说明它是在补定义、做过渡，还是在收束前文
3. 用白话翻成一层
4. 给出前后必须一起看的 1 到 3 条邻近命题

### 场景 C：用户想系统重读

按主题重排，而不是死守线性顺序：

- 世界与事实
- 图像与命题
- 逻辑与真值函数
- 哲学澄清
- 边界、神秘与沉默

## 陪读时的提问原则

只问最少的问题。

优先问这一个：

- 你现在是完全没读过，还是卡在某一段？

如果用户没回答，也可以直接默认从入门路径开始。

## 每轮最好长什么样

### 模板

1. 这一段在干什么
2. 你只需要抓住的一个动作
3. 一句白话翻译
4. 一个高频误读
5. 下一步阅读停点

## 新手友好的三条提醒

### 1. 不要一开始就执着于每个术语的最终定义

先看它在整条论证链上的位置。

### 2. 不要孤立阅读单个金句

命题编号之间的关系比单句更重要。

### 3. 对读不懂保持正常心

这本书的压缩度极高。很多难点不是你笨，而是文本本身就故意极度浓缩。

## 可以直接给用户的陪读入口

- `今天先带我读前言和命题 1`
- `陪我啃 2.1 到 2.225`
- `我卡在 4.1212，带我一点点拆`
- `按主题带我重读，不要逐条硬讲`

## 陪读模式的停止规则

不要一次推进太远。

默认一轮只覆盖：

- 一个主命题
- 或一个清晰的编号簇
- 或一个主题板块

宁可读慢一点，也不要把用户一次性淹死。
