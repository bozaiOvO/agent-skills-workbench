# Source Notes

## 本 skill 的主要来源

### 一手文本

- 《Tractatus Logico-Philosophicus》公共文本
- 主要用于确认：
  - 七条主命题结构
  - 编号推进方式
  - 命题之间的基本论证走向

### 二手参考

- Stanford Encyclopedia of Philosophy 的 Wittgenstein 条目
- 主要用于确认：
  - 早期维特根斯坦的主流理解框架
  - 图像理论、逻辑形式、说与显示、梯子等核心争议点
  - 早期与后期维特根斯坦的区分

## 为什么只用这两层

这次做的是“单书框架 skill”，目标是把《逻辑哲学论》本身蒸馏成可用接口，而不是做维特根斯坦学术史全景。

因此优先级是：

1. 文本结构
2. 权威解释中的共识与争议
3. 不额外堆太多旁支材料，避免把 skill 做散

## 当前版本的可信度策略

- 文本结构：高
- 主干模型：高
- 争议点概览：中高
- 对细部学界争论的裁决：低到中

也就是说：

- 用它入门、陪读、建立结构，足够稳
- 用它替代专业维特根斯坦研究，不够稳

## 后续可升级方向

如果以后你愿意继续升级这本 skill，可以补三类材料：

1. 你自己的精读笔记
2. 你固定使用的中文译本摘录与术语对照
3. 更细的学术解释路线，比如 resolute reading 与传统 reading 的区别

这样它会从“稳健框架版”进化成“你的工作台版”。
