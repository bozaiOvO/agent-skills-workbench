# Tensions And Boundaries

## 使用这本书时必须带着的边界

### 1. 这是早期维特根斯坦，不是后期维特根斯坦

如果用户问“语言游戏”“家族相似”，那已经是另一阶段的问题。

不要偷换。

### 2. 对象与基本命题并没有被经验性地讲清

这恰恰是长期争议来源之一。

因此：

- 可以讲文本如何需要它们
- 不能装作文本已经把它们完全落地

### 3. 说与显示是核心，也是最大争议区

可以把它当作本书边界思想的核心枢纽，但不要把某一种解释装成唯一标准。

### 4. 梯子并不等于“前面都白说”

更稳妥的理解是：

- 前面的结构在执行一种澄清工作
- 到了结尾，读者要看到这些表达的限度

但如何精确理解这一步，解释上并不统一。

### 5. 命题 7 不是万能挡箭牌

“不可说”不等于：

- 不必分析
- 不必区分
- 一切都神秘而崇高

很多时候，真正需要做的是先确认问题是不是被错误语言形式伪装了。

## 这本书擅长处理什么

- 概念混乱
- 命题有没有意义
- 事实与语言的关系
- 哲学问题是不是被语法制造出来
- 为什么有些内容只能在结构中显示

## 这本书不擅长替代什么

- 经验研究
- 历史考证
- 心理治疗
- 政策建议
- 具体生活决策的全部价值冲突

## 翻译边界

本 skill 主要依据英文公共文本和权威二手解释搭骨架。

因此要承认：

- 英文中的 proposition / picture / sense / show / say
- 中文常见译法中的 命题 / 图像 / 意义 / 显示 / 说出

它们不是完全一一重合的。

必要时应提醒用户：术语理解可能受到译本差异影响。

## 解释学上的最低诚实

回答时尽量分开：

1. 文本直接结构
2. 常见解释
3. 我的工作性推断

最忌讳的是把自己的整理，伪装成作者写明的结论。
