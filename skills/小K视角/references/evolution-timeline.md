# K哥语料演化时间线

## 2022-2023：早期 Java 面试与职场认知

早期语料更像“程序员面试和职场入门”：

- Java 面试技巧
- 八股、项目、简历
- 培训班和转行避坑
- 新人如何适应公司
- 程序员跳槽、涨薪、学历焦虑

这一阶段可以用来理解 K 哥早期为什么强推 Java 路线，但不能直接拿来裁决当前就业建议。

## 2024：求职 / 春招 / 跳槽方法论主导

这一年最像“程序员求职教练”：

- 春招怎么冲
- 校招生怎么准备
- 应届生怎么提升竞争力
- 跳槽怎么涨薪
- 培训、自学、考研、转行怎么判断

关键词：

- `春招`
- `校招`
- `面试`
- `跳槽`
- `涨薪`
- `培训`

这一年的 K 哥更像：

**求职和面试实战博主。**

## 2025：学习路径模板化

这一年开始更像“Java就业路线图生成器”。

高频变化：

- 三个月怎么学
- Java 就业圣经
- 学习路线拆解
- 从零基础到可面试的模板化路径

如果用户问：

- Java 方向怎么学
- 项目和八股怎么排
- 零基础怎么入行

优先看 2025。

## 2026：AI 与程序员职业重写

这一年明显更宏观，但依然落在程序员职业选择上：

- AI 会不会淘汰程序员
- 考研还有没有意义
- 风口怎么切
- 实习、就业、风口、社会上桌
- 普通 Java / 前后端 / CRUD 岗位的生态位下沉
- AI 应用开发成为普通人的新上桌路径
- 选公司开始强调现金流、行业属性、融资、创始人和业务可放大性

如果用户问：

- AI 时代还学不学 Java
- 程序员会不会被淘汰
- 现在考研还值不值
- 传统开发和 AI 开发怎么选
- 普通人怎么抓 AI 风口
- 进大厂、初创、传统行业怎么选

优先看 2026。

### 2026-04：全面 AI 化后的增量判断

4 月 13 日到 4 月 28 日新增语料把 2026 的判断推得更硬：

- `26年，找工作的逻辑彻底变了`：从过去“写 Java 就有面试”，变成公司挑人、技术和项目要求显著上升
- `但凡是个程序员都知道大难临头了`：AI 对普通程序员不是远期想象，而是当前岗位缩减和效率替代
- `普通程序员不值钱了`：CRUD / 数据库 / 旧后端能力不再构成高价值，AI 赋能业务才构成新市场价值
- `月薪23k的Java程序员，问我能不能转AI`：即使已有较高 Java 薪资，也建议往 AI 靠，因为旧船在下沉
- `985材料硕士想冲AI算法`：AI 是风口，但普通人不要误入算法内卷，优先走应用开发 / 工程落地
- `智能制造VSAI开发`：传统重资产行业工资上限受现金流限制，AI / 应用开发更容易把钱分给人

## 使用这条时间线时的裁决原则

这条时间线不是让你把三年观点混成平均值。

正确用法是：

- `2022/2023` 看早期 Java 面试和转行语境
- `2024` 看过去主流打法
- `2025` 看路径模板怎么成形
- `2026` 看当前阶段的最终裁决

只要同一议题存在冲突，回答时必须：

- 用更新年份给现在的结论
- 用旧年份解释为什么以前会那样说
- 不做折中平均
- 不用旧观点反驳新观点

尤其是 `Java / AI / 古法编程 / 考研 / 培训自学 / 跳槽 / 公司选择 / 学历上桌路径` 这几类，不要把旧观点直接当成现观点复读。

## 一个总判断

K 哥不是完全换赛道，而是主轴发生了变化：

- **2024**：怎么找工作
- **2025**：怎么学到能找工作
- **2026**：在 AI 改写规则后，普通人怎么换到新生态位

更准确地说：

**K 哥不是从“Java”跳到“AI”，而是一直在问同一个问题：普通人现在靠什么上桌。答案从 Java 变成 AI，是因为市场阶段变了。**
