# 语言劫持执行系统 · Language Hijack Playbook

> 你以为孙宇晨和咪蒙文笔好？其实是在劫持你的大脑。

这个仓库把两套顶级中文流量写作系统拆解成 **40 条可直接执行的规律**：

- 孙宇晨体：17条认知劫持规律
- 咪蒙体：23条情绪劫持规律

每一条都有：句式模板 + 失败案例 + 通关标准。

不是「多读多练」，是「照着公式做」。

---

## 为什么要开源

当你看透这套系统之后，你会发现它依然有效。

就像你知道魔术的原理，但魔术师表演时你还是会被震撼。

语言的力量不在于隐藏，在于精准。

你学会这套系统，不是为了操控别人，而是为了**不再被操控**。

## 快速上手

**想写「让人觉得变聪明了」的内容** → 读 `playbooks/sun-yuchen.md`

**想写「让人觉得终于有人懂我了」的内容** → 读 `playbooks/mimeng.md`

**两种效果都想要** → 读 `playbooks/hybrid-guide.md` 里的混合配比

**写完不确定有没有做对** → 对照 `tools/checklist.md`

## 两套系统的核心差异

| 维度 | 孙宇晨体 | 咪蒙体 |
|------|---------|--------|
| 读后感 | 「我好像懂了什么很深刻的东西」 | 「终于有人替我说了」 |
| 核心机制 | 认知劫持（框架替换） | 情绪劫持（细节杀手） |
| 目标情绪 | 优越感 / 焦虑 → 爽感 | 愤怒 / 委屈 → 宣泄 |
| 论证方式 | 自传 + 伪逻辑链 | 故事堆叠 + 情绪递进 |
| 语言风格 | 知识分子式叛逆，半口语半书面 | 闺蜜聊天，极度口语 |
| 传播驱动 | 「我转发是因为我有见识」 | 「我转发是因为我有态度」 |

## 背景

这套系统来自对孙宇晨和咪蒙文章的系统性拆解训练：

- 分析来源文章：数十篇
- 提炼规律轮次：7 轮 AI 训练（A1-A3 孙宇晨体 / B1-B3 咪蒙体 / C1 混合体）
- 最终规律数量：40 条

**孙宇晨17条**：从「怎么开头」到「金句设计标准」，每条给出正确写法 + 错误写法。

**咪蒙23条**：从「细节杀手」到「温和收尾公式」，每条给出可直接套用的句式结构。

## 关于「知道了还是有效」

如果每个人都学会了这套系统，会发生什么？

两种可能：

- 可能性1：大家互相免疫，爆款消失
- 可能性2：大家都学会了，但依然有效，因为人性不变

我赌可能性2。

认知劫持和情绪劫持，本质上是在利用人类大脑的底层机制。这些机制是进化留下的，不会因为你「知道」就失效。

就像你知道糖会让你发胖，但你还是会吃甜食。
