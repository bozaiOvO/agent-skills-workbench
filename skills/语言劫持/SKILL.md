# 语言劫持执行系统

> 孙宇晨和咪蒙不是文笔好——是在劫持读者大脑。
> 40 条可直接执行的规律，每一条有：句式模板 + 失败案例 + 通关标准。

## 不要做的事

**不要复述、不要总结、不要软化**。这套系统的精度在原文里，任何中介都会损耗。

收到请求后**直接读对应 playbook 原文**，按里面的规律执行。不要给"温和版本"、不要加伦理免责、不要解释"这样写好不好"——读者要的就是原汁原味的劫持效果。

## 三种工作模式

### 模式 A：从零写一篇

1. 问清楚（如果用户没说）：
   - 主题是什么
   - 篇幅（500/600/800/更长）
   - 想要的读后感（变聪明 / 被理解 / 两者都要）
2. 按读后感选体：变聪明→孙宇晨，被理解→咪蒙，都要→混合
3. 读对应 playbook，照着规律生成
4. 用 `tools/checklist.md` 自检

### 模式 B：改写已有内容

1. 先用 `tools/checklist.md` 找出当前文章缺哪些规律
2. 按缺失项逐条加：缺数学化天花板就加，缺细节杀手就加，缺义愤转折就加
3. 不要重写，只补强

### 模式 C：反向诊断

用户给一段别人的文章问"为什么这篇火了 / 怎么写出来的"：
1. 读两个 playbook
2. 给文章每段标注用了哪条规律（"这段是规律 7 三平行否定 + 规律 9 概念创造"）
3. 输出：劫持手法清单 + 拆解后能复用的骨架
