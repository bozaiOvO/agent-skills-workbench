# 孙宇晨体执行手册 · 17条认知劫持规律

## 核心定位

**认知爽感制造机**。读者读完觉得「我变聪明了 / 我看透了」。

底层机制：认知偏差制造 + 幸存者偏差 + 伪二元对立 + 框架替换。

读后感：**「我好像懂了什么很深刻的东西。」**

---

## 速查参数

```yaml
文章结构:   反常识观点 → 自传论证 → 框架替换 → 金句升华
段落长度:   中等（50-150字/段）
句子长度:   长短交替（长句铺垫，短句收尾）
语气:       自信笃定，略带傲慢的知识分子式叛逆
人称:       以「我」为主，穿插「你」和「我们」
标志词汇:   认知 / 思维 / 本质 / 真相 / 底层逻辑 / 财富自由 / 赛道 / 建造
情感基调:   焦虑 → 兴奋 → 优越感
金句密度:   每 300-500 字一句
禁忌:       不能示弱 / 不能承认运气 / 不能用「也许」「可能」等犹豫词
```

## 执行规律（17条）

### ▌开头

---

**规律1：开头方式由篇幅决定**

| 篇幅 | 开头方式 |
|------|---------|
| 800字以上 | 第三人称故事开头 + 主观判断句（「他完了」式） |
| 600字以下 | 直接刺耳判断句（「绝大多数人理解的X，是在浪费生命」） |
| 500字以下 | 短问题+悖论答案（「三十岁一事无成？恭喜你，你终于有资格开始了。」） |

故事开头最优结构：**同等起点 + 两人对比 + 具体数字 + 结局悬殊**

---

**规律2：框架替换必须触碰人格尊严**

> 核心：在新框架里，反方永远无法反驳——因为反驳等于承认自己是懦夫

❌ 错误：换成抽象概念（「时间归谁定价」）

✅ 正确：换成关于人的本质状态（「你是主动选择，还是被恐惧推着走」）

通关标准：读者要反驳你的新框架，必须先承认某个负面人格标签。

---

### ▌论证

---

**规律3：自传论证必须极度具体**

必须包含：**年份 + 机构名/地点 + 具体动作 + 结果**

❌ 模糊：「我创业成功了」（失去50%说服力）

✅ 具体：「2011年从北大提前毕业，all in比特币，2013年创办锐波科技」

---

**规律4：权威名字堆叠**

具体机构名 + 具体人名，越顶级越好。

示例：湖畔大学 + 马云 + 冯仑 + 史玉柱

越具体越可信，避免「某著名投资人」这类模糊表达。

---

**规律5：数学化天花板**

把限制精确计算到数字，让天花板变成物理定律。

示例：「月薪3万 = 每小时约125块。你的时间就值这个价。」

效果：读者产生「被数学困住」的压迫感，这时候你给出路，他会觉得你在拯救他。

---

**规律6：反向论证——展示「早成功」的陷阱**

不说「晚成功好」，而是说「早成功可能是陷阱」。

示例：「二十几岁成功的人，三十五岁被房贷、家庭、年龄锁死。」

效果：让读者主动抛弃原框架，而不是接受新框架。这比直接说服有效10倍。

---

**规律7：三平行否定 = 三项具体自由**

把「什么都没有」分解成三个具体的「没被绑住的事」。

示例：
> 「你没有一份食之无味弃之可惜的工作。你没有一段用房贷维系的婚姻。你没有一个不得不维持的人设。」

三个否定比一个抽象的「自由」更有说服力。

---

**规律8：单一中心类比**

每篇只选一个核心比喻，贯穿全文，不堆砌。

示例：操作系统（Windows vs macOS）/ 铁锹 vs 挖矿机

多个比喻会互相稀释，一个打透比三个并列更有力。

---

**规律9：概念创造**

每篇至少造一个新词。

选材标准：读者早有感受但从没命名的现象。

示例：「认知落差」「集体催眠」「集体债务感」

效果：你给一个模糊的感受命名，读者会觉得「对，就是这个词，我一直想不出来」。

---

**规律10：预设反驳升级版**

让对方的反驳本身成为你论点的新证据。

示例：「如果你认为社交是建立机会的主要路径，说明你还没有建立任何稀缺价值。」

不是反驳你的观点，而是把你的反驳变成他论点的证据——这是认知劫持的最高境界。

---

**规律11：自我神化的谦虚包装**

句式：**「不是因为A（外部条件/运气），而是因为B（自身能力/判断力）」**

表面谦虚，实际是在强化「我的成功源于我的认知」的叙事。

---

**规律12：承认不公平 + 封死退路**

「这不公平，但这是事实。」

先软化（承认不公平），再封死逃跑路线（但这是事实，不接受也没用）。

---

### ▌金句与结尾

---

**规律13：金句设计标准**

三要素：**视觉化行为对比 + 绝对化词（永远/从来/唯一）+ 令人轻微不适**

示例：「在二十五岁那年就已经死了——只不过要到六十五岁才下葬。」

分析：「死了」和「下葬」是视觉化行为对比，「已经」是绝对化词，「二十五岁就死了」令人轻微不适。

---

**规律14：结尾重框落到「时间用法」**

❌ 错误：落到「谁的目标」（太抽象）

✅ 正确：落到「你在这段时间是在焦虑，还是在建造」（可操作）

结尾重框要让读者知道下一步做什么。

---

**规律15：结尾必须有具体行动指令**

示例：「停下来。不是让你停下焦虑。是让你停下来想清楚：你到底要建造什么。」

哲学陈述不够，必须给一个读者明天能执行的动作。

---

**规律16：结尾两种选择**

- **半退让锁死**：「我不是让你X，我是让你先问自己……」
- **金句戛然而止**：最强那句话之后不再解释

不要用解释稀释金句的力量。

---

**规律17：篇幅纪律**

| 篇幅 | 结构 |
|------|------|
| 500字 | 短问 + 悖论 + 一论点 + 一金句 |
| 600字 | 一个命题打透，不多线 |
| 800字 | 2-3个论证层次 |
| 任何篇幅 | 在倒数20%位置放全文最强金句 |

---

## 金句速查库

- 「在二十五岁那年就已经死了——只不过要到六十五岁才下葬。」
- 「这是最残酷的时代，只要稍稍懈怠一点，就会前功尽弃。这是最温柔的时代，只要稍稍坚持一下，就会脱颖而出。」
- 「稳定是这个世界不再需要你，任何一个人都能替代你。」
- 「人人生而独立，独立从来无须获得，而是一种既定事实。」

金句特征：
1. 对仗结构占80%以上
2. 使用绝对化判断词：从来 / 永远 / 唯一 / 一切
3. 将个人选择包装成哲学命题
4. 句子具有「拿来发朋友圈」的传播潜力

## 常见错误

| 错误行为 | 正确做法 |
|---------|---------|
| 用「也许」「可能」等犹豫词 | 换成笃定的陈述句 |
| 论证时只说「我成功了」 | 加年份+机构名+具体动作+结果 |
| 结尾落到抽象感受 | 落到明天能执行的具体动作 |
| 堆砌多个比喻 | 选一个，贯穿全文 |
| 框架替换换成抽象概念 | 换成关于人的本质状态（触碰人格尊严）|
| 金句后继续解释 | 戛然而止 |
