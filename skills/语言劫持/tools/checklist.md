# 自检清单 · 写完一篇后对照这里

## 孙宇晨体自检（17条对应）

写完后逐项打勾：

### 开头
- [ ] 开头方式和篇幅匹配（800字以上用故事，500字以下用短问+悖论）
- [ ] 有框架替换，且替换后触碰了人格尊严（不是换成抽象概念）
- [ ] 反方要反驳你，必须先承认某个负面人格标签

### 论证
- [ ] 自传论证有：年份 + 机构名 + 具体动作 + 结果（四要素不缺）
- [ ] 没有用「也许」「可能」等犹豫词
- [ ] 没有示弱，没有承认运气
- [ ] 有数字化（把某个限制算成精确数字）
- [ ] 全文只用一个核心比喻，没有堆砌
- [ ] 创造了至少一个新词（读者有感受但没命名过的现象）

### 金句
- [ ] 最强金句在全文倒数20%位置
- [ ] 金句有：视觉化行为对比 + 绝对化词 + 轻微不适感
- [ ] 金句之后没有继续解释（戛然而止）

### 结尾
- [ ] 结尾落到「时间用法」或「明天能执行的具体动作」，不是抽象感受
- [ ] 每300-500字有一句金句（密度达标）

## 咪蒙体自检（23条对应）

### 开头
- [ ] 开头方式和文章目的匹配（愤怒类/对号入座类/共情类选对了）
- [ ] 故事来源用「我闺蜜/我朋友」，不是「我读者」
- [ ] 有「我忍了X次，第X+1次没忍住」的张力结构（如果有说实话的场景）

### 场景与细节
- [ ] 每个重要场景有一个超级具体的微细节（一个词/符号/动作）
- [ ] 父母/电话场景有三句递进（情感压力→同龄比较→质疑价值）
- [ ] 情绪崩溃用延迟显现（当时没哭，事后才哭），不是直接写崩溃
- [ ] 每段不超过3行

### 案例与论证
- [ ] 选了读者能认出自己的案例（不是最戏剧性的案例）
- [ ] 案例有递进感（micro→macro），不是三个平行场景
- [ ] 有义愤转折点：一个人说错了话→作者替读者爆发
- [ ] 外归因之前，有三个具体行动场景验证读者努力过

### 金句与结尾
- [ ] 用了金句核心公式：「X最大的X，不是A，是B」（至少一次）
- [ ] 解放段给的是三个具体社交压力场景，不是抽象的「你不需要证明任何事」
- [ ] 实操建议是明天能用的行为，不是心态建议
- [ ] 结尾用了原词回扣（开头/标题的核心词）
- [ ] 金句分布在全文（每3-4段一个），不是全堆结尾
- [ ] 没有理中客，没有两边讨好
- [ ] 没用学术语言

## 通用检查

- [ ] 全文最强的那句话能不能单独截图传播？
- [ ] 读完的人会觉得「我变聪明了」还是「终于有人替我说了」？（确认目标效果）
- [ ] 有没有用过「也许」「可能」「有些人」这类模糊词弱化了判断？
- [ ] 开头第一句话能不能直接让人想继续读？
